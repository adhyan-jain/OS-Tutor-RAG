# Repo map

What every top-level piece is for, and which document to read for what. This file
replaces the old `DEAD_CODE_AND_DOCS_AUDIT.md`, `current_status.md`, `DELAYED_TASKS.md` and
the scattered hand-off notes (their still-true content is in `FINDINGS.md`, "Technical debt").

The repo holds two things: the **OS Tutor** (a RAG chatbot with a Socratic tutoring layer)
and two **research tracks** about it (the RAG technique study, and Reference-Choice
Robustness, RCR).

## The application

| Path | What it is |
|---|---|
| `src/` | The RAG pipeline: `ingestion/` -> `chunking/` -> `retrieval/` -> `reranking/` -> `diversification/` -> `context_expansion.py` -> `generation/`, wired by `pipeline.py`, configured in `config.py`. |
| `src/tutor/` | The tutoring layer: concept-state machine, graded Socratic questions, hints, quiz, triage, follow-up chips, authored course knowledge. Policy is code, not prompt; the model only phrases. |
| `api/` | FastAPI app. `routes/chat.py` streams one tutoring turn over SSE; `routes/tutor.py` serves the course map, progress and reset; `routes/session.py` is the in-memory per-thread store. |
| `frontend/` | Next.js UI (chat, starters, follow-up chips, progress) and the `/research` explainer page (`app/research/`, `components/research/`). |
| `data/raw` | Source course material (decks, OSTEP chapters, handouts). `data/index` and `data/processed` are generated by `src/build_index.py` / `scripts/reindex.py`. |
| `tests/tutor/` | Tests for the tutoring layer (scripted dialogues, grading keys, intents, follow-ups). |
| `DEPLOYMENT.md`, `docker-compose.yml`, `requirements*.txt` | Container deployment. |

## Evaluation of the RAG pipeline

| Path | What it is |
|---|---|
| `eval/ragas_eval.py` | The mass evaluator: runs config variants against `eval/eval_set.json` (26 golden questions) with the RAGAS judge. Shares scoring with `src/evaluation.py`. |
| `eval/retrieval_eval.py`, `rank_diagnosis.py`, `reranker_eval.py`, `stage_tuning_eval.py` | Retrieval-only measurements (no LLM judge): recall@k, MRR, rank diagnosis, reranker and stage-size experiments. |
| `eval/*results.md`, `eval/logs/` | Recorded outputs of prompt/temperature comparisons and sweeps. |
| `FINDINGS.md` | The measured results: defects F1-F16, analyses A1-A20, run history, technical debt, caveats. Read this first. |
| `HYPOTHESES.md` | Open hypothesis queue with falsification criteria. |
| `LEARNING_GUIDE.md` | Personal study guide to every technique in the pipeline (git-ignored, deliberately unpublished). |
| `docs/GUIDE_PART2_RAG_CHATBOT_PIPELINE.md` | Part 2 of the presentation guide: the RAG chatbot end to end. Exact inputs per stage, how each RAGAS metric is computed, a worked example, the chat turn and tutoring layer, component and API reference, talk tracks, hostile Q&A. |
