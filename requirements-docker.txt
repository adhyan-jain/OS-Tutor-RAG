# CPU-only dependencies for the api/Dockerfile image.

# inside src/evaluation.py functions api/ never calls).
# tiktoken IS kept below -- unlike those, it's a hard top-level import.
#
# Do not edit requirements.txt to "fix" this -- that file is what the
# user's own GPU dev machine installs from.
